## ▽ 빠른 마나 소모, 빠른 마나 재생, 마나 수급이 이뤄짐

- 플레이어 상세
    
    ### 플레이어 상세 사항
    
    | 기본 최대 체력 | 100 |
    | --- | --- |
    | 기본 최대 마나 | 100 |
    | 초당 마나 재생량 | 10 |
    | 그래플링 훅 쿨타임 | 1.2 |

## ▽ 웨이브를 마칠 때마다 보상을 받고, 다음 페이즈를 준비함

- 웨이브 상세
    - 웨이브 상세사항
        
        보스를 죽이기 위해 빨리 마나를 수급해서 스킬을 빨리빨리 돌려야 함
        
        쫄몹이 계속 등장해줘야 함
        
        ### 총 7웨이브로 진행.
        
        |  |  | 쫄몹 최대 스폰 | 웨이브 종료 조건 |
        | --- | --- | --- | --- |
        | • 1~3 (총 3웨이브) | 쫄몹 | 12/15/20 | 50/70/90마리 잡기 |
        | • 4 | 중간 보스 + 쫄몹 | 15 | 중간 보스 잡기 |
        | • 5~6 (총 2웨이브) | 쫄몹 | 20/30 | 50마리 잡기 |
        | • 7 | 최종 보스 + 쫄몹 | 20 | 최종 보스 잡기 |
    - 웨이브 보상사항
        
        ### 웨이브가 끝나면, 다음 웨이브 준비 시간을 가진다
        
        - 웨이브 보상 수령
            - 플레이어 스탯 강화( ▼목록 중 택일)
                - 최대 체력 증가: +20
                - 최대 마나 증가: +20
                - 초당 마나 재생량 증가: +5/+4/+3/+2/+1
            - 기본 스킬, 중급 스킬, 고급 스킬 중 하나를 택함
                - 해당 스킬에 있는 룬 중 하나를 강화 가능함 (룬 1  / 룬2  / 룬3 )
                    - 공격력 증가: +10/+8/+6/+5/+4
                    - 자원 소모 감소: -10/-7/-5/-5/-3
                - ⇒ ( 초기 ⇒ 현재 )**룬 문자를 강화할 수 있게 할까??**
                
                - 만약에 겹치는 룬 문자가 있다면, 더 강해지는 거지.
                - A만 강화햇는데, 초급 스킬이랑 중급 스킬이 같이 강해지는 거야
                - 강화는 현재 있는 룬 중에서 골라서 강화 가능
                - 그럼 자원 소모도 룬마다 해야겠네
                - 룬 별 자원소모 다 더한 게, 최종 마법 자원소모량이 되는 거야
        - 스킬 교체(미구현)
            - 1페이즈, 4페이즈마다 스킬 교체 선택지가 등장 → 추후 스킬 선택지가 많아질 경우, 조합의 재미
            - 스킬 교체 시, 강화 수치는 -1 (최소 1)
